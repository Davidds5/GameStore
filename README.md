<h1 align="center">🎮 GameStore - Sistema de Gestão para Loja de Jogos</h1>

<p align="center">
  Sistema de gerenciamento de vendas, estoque e clientes desenvolvido em Java com foco em boas práticas de Programação Orientada a Objetos.
</p>

<hr>

<h2>📌 Sobre o Projeto</h2>

<p>
O <strong>GameStore</strong> é uma aplicação de console desenvolvida em Java com o objetivo de simular o funcionamento interno de uma loja de jogos.
</p>

<p>
O sistema foi projetado utilizando conceitos sólidos de <strong>Programação Orientada a Objetos (POO)</strong>, separação de responsabilidades em camadas e tratamento de exceções, buscando simular um cenário real de negócio.
</p>

<hr>

<h2>🚨 Problema que o Projeto Resolve</h2>

<p>
Pequenas lojas frequentemente enfrentam dificuldades no controle manual de:
</p>

<ul>
  <li>📦 Estoque de jogos</li>
  <li>🛒 Carrinho de compras</li>
  <li>💰 Registro de vendas</li>
  <li>👤 Cadastro de clientes</li>
</ul>

<p>
Sem um sistema estruturado, erros como venda de produtos sem estoque, cálculos incorretos e falta de controle financeiro se tornam comuns.
</p>

<p>
O <strong>GameStore</strong> resolve esse problema ao oferecer:
</p>

<ul>
  <li>Controle automatizado de estoque</li>
  <li>Validação antes da finalização da venda</li>
  <li>Organização das vendas realizadas</li>
  <li>Tratamento adequado de exceções</li>
</ul>

<hr>
